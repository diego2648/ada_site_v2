ARTHUR ADA - SITIO WEB V2

1. Abre index.html con Live Server en Visual Studio Code.
2. Cambia el teléfono real en:
   - index.html (botón flotante y footer)
   - js/script.js (const phone)
3. Cambia el correo y zona de servicio.
4. Para TikTok, reemplaza href="#" del botón #tiktokProfile por la URL real del perfil.
5. Las galerías de proyectos se editan en projectData dentro de js/script.js.
6. Las imágenes están en /img y pueden reemplazarse conservando los mismos nombres.

FUNCIONES INCLUIDAS
- Loader animado
- Carrusel automático y manual
- Hover y microinteracciones
- Efecto 3D con mouse en escritorio
- Animaciones de entrada con IntersectionObserver
- Fondos animados CSS
- Efecto de luz que sigue el mouse
- Menú responsive
- Sección TikTok
- Galerías de proyectos en modal/pantalla completa sin salir de la página
- Navegación por flechas, teclado, miniaturas y swipe en móvil
- Formulario hacia WhatsApp
- Respeta prefers-reduced-motion
